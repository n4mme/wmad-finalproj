# Location Search - User Guide

## How to Use the Enhanced Location Search

When creating a listing (Home, Experience, or Service), you'll need to specify a location. Here's how to use the new powerful search feature:

---

## 🔍 **Method 1: Text Search**

### Step-by-Step:

1. **Type at least 2 characters** in the location field
   - Example: Type `"el"` to start seeing suggestions

2. **Wait for suggestions** (appears within half a second)
   - You'll see 5-10 location options
   - Results are sorted by relevance

3. **Browse the suggestions**
   - Each shows the full address hierarchy
   - Location type is displayed (city, town, landmark)
   - Look for the green pin icon 📍

4. **Click your desired location**
   - Location name fills the input field
   - Map automatically centers on that location
   - Coordinates are captured

### 💡 **Pro Tips:**

- **Be specific:** Type more characters for better results
  - ❌ `"el"` → Too broad (many results)
  - ✅ `"el nido"` → Specific (focused results)

- **Include province:** For popular names
  - `"san jose, palawan"` vs just `"san jose"`

- **Use landmarks:** For well-known places
  - `"white beach"` → Finds Boracay's White Beach
  - `"rizal park"` → Finds Luneta Park, Manila

---

## 🗺️ **Method 2: Map Click**

### Step-by-Step:

1. **Scroll down to the Interactive Map** section

2. **Click anywhere on the map**
   - Zoom in for precision using mouse wheel
   - Pan around by dragging

3. **Watch the magic happen:**
   - A marker appears where you clicked
   - System automatically detects the address
   - Location input field updates with the address
   - You'll see: "🔄 Fetching address..."

4. **Verify the location** in the input field above

### 💡 **Pro Tips:**

- **Zoom in first** for accurate placement
- **Use map for remote areas** with no street addresses
- **Combine methods:** Search first, then fine-tune with map

## 🚨 **Common Issues & Solutions**

### Problem: "No locations found"

**Solutions:**
1. ✅ Check spelling (minor typos are okay)
2. ✅ Try a broader search (city instead of street)
3. ✅ Use the map method instead
4. ✅ Add province name for clarity

### Problem: Wrong location suggested

**Solutions:**
1. ✅ Type more specific terms
2. ✅ Include province or region
3. ✅ Use the map to pinpoint exact spot
4. ✅ Scroll through all 5-10 suggestions

### Problem: Too many results

**Solutions:**
1. ✅ Add more context: `"el nido, palawan"` instead of just `"el"`
2. ✅ Include location type: `"boracay beach"` vs just `"boracay"`

### Problem: Can't find a very specific address

**Solutions:**
1. ✅ Search for the nearest landmark or main road
2. ✅ Use the map to click the exact location
3. ✅ Search for the barangay or subdivision name

## ✨ **Best Practices**

### For HOMES 🏠
```
Best format: Street, City, Province
Example: "Seaside Avenue, Parañaque, Metro Manila, Philippines"

Tips:
- Include street name for accuracy
- Specify city/municipality
- Use map to mark exact property location
```

### For EXPERIENCES 🎈
```
Best format: Landmark/Area, City, Province  
Example: "White Beach, Boracay, Aklan, Philippines"

Tips:
- Use well-known landmark names
- Activity location, not accommodation
- Be specific about the meeting point
```

### For SERVICES 🛎️
```
Best format: District/Area, City, Province
Example: "BGC, Taguig, Metro Manila, Philippines"

Tips:
- Use business district or neighborhood name
- City-level accuracy is usually sufficient
- Can be service delivery area, not just one address
```

## 🎓 **Advanced Tips**

### 1. Using Both Methods Together
```
Step 1: Search for general area ("Palawan")
Step 2: Browse suggestions, pick province
Step 3: Zoom in on map to exact location
Step 4: Click map for precise coordinates
```

### 2. For Remote Locations
```
If place has no address:
1. Search nearest town/municipality
2. Zoom in on map
3. Click exact spot
4. System will provide coordinates + nearest address
```

### 3. For Multiple Properties
```
If you have several properties:
1. Create separate listings for each
2. Use map to ensure accuracy for each
3. Make location names distinct
   - "Beachfront Villa, El Nido"
   - "Mountain Cabin, El Nido"
```
